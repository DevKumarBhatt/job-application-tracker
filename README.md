# 💼 Job Application Tracker & Analytics Dashboard

A Python-based web application for managing, tracking, and analyzing job applications from a single dashboard.

## 🚀 Features

- Add job applications
- Edit application details
- Delete applications
- Track application status
- Search applications by company
- Filter applications by status
- Dashboard with application metrics
- Application status visualization
- Interview reminders
- Follow-up reminders
- Export applications to CSV
- SQLite database for persistent storage
- Custom Streamlit UI

## 🛠️ Tech Stack

- Python
- Streamlit
- SQLite
- Pandas
- Matplotlib
- Git & GitHub
